🏋️ GymControl

Sistema de Gestión de Gimnasio

📋 Descripción

GymControl es un sistema integral de gestión para gimnasios y centros de entrenamiento. Diseñado para optimizar la administración de miembros, clases, equipos y pagos en una plataforma centralizada y fácil de usar.

✨ Características

  • Gestión de miembros y afiliaciones
  • Control de asistencia y reservas de clases
  • Manejo de pagos y facturación
  • Reportes y estadísticas
  • Administración de equipos e instalaciones
  • Sistema de notificaciones
  • Entrega de trabajo practico

🛠️ Tecnología

C# .NET SQL Server WinForms

Desarrollado con C# y .NET para máxima compatibilidad y rendimiento.
