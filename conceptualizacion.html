🏋️ GymControl

Sistema de Gestión para Gimnasio

En la actualidad, el "Gimnasio FitZone" administrado por el señor Carlos gestiona todos sus procesos operativos, como el registro de membresías, control de pagos, horarios de clases y asistencia, de manera íntegramente manual mediante el uso de cuadernos y planillas físicas. Esta metodología de trabajo genera una problemática concreta: la incapacidad de mantener un control preciso en tiempo real de los miembros activos. Como consecuencias observables de esta situación, el negocio experimenta una notable lentitud en el registro de nuevos miembros, errores recurrentes en el cobro de cuotas mensuales, dificultad para gestionar horarios de clases y pérdidas económicas ocasionadas por pagos no registrados o cobros duplicados.

2. Definición del Problema

Situación Actual

Actualmente, el señor Carlos registra las membresías, cobros mensuales y horarios de clases utilizando cuadernos y planillas manuales.

Problemática Concreta

El registro manual provoca lentitud en la inscripción de nuevos miembros, errores en el seguimiento de pagos de cuotas, dificultad para gestionar horarios de clases y entrenamientos personalizados, y pérdidas económicas por pagos no cobrados o duplicados. Además, es imposible acceder rápidamente al historial de asistencia de los miembros.

3. Propósito y Objetivos

Objetivo General: Desarrollar un sistema informático que permita gestionar membresías, pagos, horarios de clases y asistencia del gimnasio FitZone de forma rápida, centralizada y automatizada.

Objetivos Específicos

  1. Registrar nuevas membresías con información de miembros (nombre, contacto, plan de pago).
  2. Gestionar automáticamente el cobro y seguimiento de cuotas mensuales.
  3. Administrar horarios de clases y entrenamientos personalizados.
  4. Registrar asistencia de miembros al gimnasio.
  5. Generar reportes de ingresos mensuales y membresías activas.

4. Alcance del Proyecto

✅ Incluye (dentro del alcance):
  • Módulo de gestión de membresías (altas, bajas y modificaciones).
  • Módulo de control de pagos y cuotas mensuales.
  • Módulo de horarios de clases y entrenamientos.
  • Control de asistencia mediante registro manual o código QR.
  • Alertas de pagos pendientes o cuotas atrasadas.
  • Reportes de ingresos y membresías activas.
❌ No incluye (fuera de alcance):
  • Pago en línea integrado directamente en el software (se usará pasarela externa).
  • Aplicación móvil para miembros (solo versión web para administrador).
  • Integración con máquinas de gimnasio inteligentes.
  • Facturación electrónica legal con autoridades fiscales.

6. Justificación / Viabilidad

Viabilidad Técnica

El equipo cuenta con los conocimientos necesarios en lenguajes de programación web para desarrollarlo.

Viabilidad Operativa

La interfaz se diseñará con botones grandes y flujos sencillos, asegurando que el personal del gimnasio pueda utilizarlo sin conocimientos técnicos avanzados.

Viabilidad Económica

Al utilizar herramientas de código abierto y un servidor local o en la nube económico, los costos de desarrollo e implementación serán mínimos para el gimnasio.

7. Visión General de la Solución

El sistema será una aplicación web que permitirá registrar nuevos miembros de forma rápida, asignarles un plan de pago mensual y registrar automáticamente sus cuotas. Al llegar al gimnasio, los miembros marcarán su asistencia. El sistema generará alertas de pagos pendientes y reportes mensuales de ingresos para que el señor Carlos pueda monitorear el estado financiero del negocio.

8. Glosario de Términos

Término Definición
Membresía Suscripción mensual o anual de un cliente al gimnasio.
Cuota mensual Monto de pago que debe realizar el miembro cada mes para mantener su membresía activa.
Entrenamiento personalizado Sesión de entrenamiento diseñada específicamente para un miembro por un entrenador.
Plan de pago Modalidad de suscripción (mensual, trimestral, anual) con su respectivo precio.
Asistencia Registro de la fecha y hora en que un miembro ingresa al gimnasio.

9. Riesgos Iniciales

Riesgo Impacto Estrategia de Mitigación
Baja disponibilidad del cliente
Tiempo limitado del señor Carlos debido a la operación continua del gimnasio.		 Alto Coordinar reuniones breves de máximo 20 minutos en horarios con poco movimiento, enviar prototipos visuales y usar comunicación asincrónica por mensajes.
Resistencia al cambio
Posible dificultad del personal para adaptarse de registros manuales a software.		 Alto Diseñar una interfaz extremadamente simple, realizar capacitaciones prácticas presenciales y entregar un manual de usuario visual paso a paso.
Datos incompletos
Registros manuales previos inconsistentes (nombres duplicados, precios desactualizados).		 Medio Entregar una plantilla estándar para la carga inicial de datos y dedicar una sesión previa para organizar y unificar la información.
Retraso en cronograma
Intentar abarcar demasiadas funciones avanzadas.		 Medio Priorizar estrictamente el Módulo de Membresías y Pagos (MVP) en las primeras fases y mover funciones secundarias a etapas posteriores.

10. Selección Tecnológica Preliminar

Componente Elección Justificación
Lenguaje de programación JavaScript Permite usar un mismo lenguaje tanto en el cliente como en el servidor, agilizando el desarrollo y contando con una amplia variedad de librerías para la gestión de datos.
Framework React (Front-end) + Node.js con Express (Back-end) Permite construir una interfaz rápida, dinámica e intuitiva para el registro de miembros, junto con un servidor liviano y eficiente para procesar las consultas del inventario.
Base de datos PostgreSQL (o MySQL) Es un motor relacional gratuito y robusto que garantiza la integridad y consistencia de los datos (membresías, pagos y asistencia) mediante transacciones seguras.
